KHUSHBOO & VISHAL — WEDDING INVITATION

FILES
- index.html: standalone, self-contained interactive invitation. Artwork is embedded, so the HTML works without a separate image file.
- wedding-artwork.webp: artwork separately for easy image sharing.

OPENING
1. Download index.html to a computer or phone.
2. Open it with a web browser (Chrome, Safari, Edge, etc.).
3. Tap the gold wax seal to open the invitation.

SHARING ON WHATSAPP
- Best experience: publish index.html with free GitHub Pages, then send the resulting https:// link in WhatsApp. The invitation opens in the recipient's browser and keeps the envelope animation interactive.
- You can attach index.html in WhatsApp as a Document. Recipients may need to download it and open it in a browser; some phones and WhatsApp previews do not run local HTML files directly.
- For a quick visual share, send wedding-artwork.webp. It is a picture, not the interactive invitation.

FREE GITHUB PAGES HOSTING
1. Sign in to GitHub and create a new public repository, e.g. khushboo-vishal-wedding.
2. Upload index.html (the self-contained HTML is enough).
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
5. Once published, copy the website's https:// URL and send it to guests on WhatsApp.
